# 改ざんして、検出を確かめる

自分の一票を集計から外す操作と、集計後の得票数を書き換える操作では、壊れるつながりが違います。前者では掲示板と集計入力、後者では計算結果と表示が食い違います。

このデモでは、その違いを確かめるために集計時のシナリオを選べます。S0 は変更を加えない基準です。S1・S3・S5 は一票を集計入力から外し、S2・S4 は画面へ出す得票数だけを変えます。

どちらの改ざんでも、STARK レシート自体は正常に検証できる場合があります。前者では「63 票を受け取り、一票の未提示を記録した計算」が正しく実行され、後者では「元の 64 票の正しい集計」がそのまま証明されるためです。検証画面は、この証明に結びついた結果を掲示板や表示値と比較して、集計全体の失敗を見つけます。

[各シナリオ](scenarios.md)では、B を選んだインデックス 0 の一票と、63 票のボット票について、何を変え、どの証拠に差が出るかを追います。
