# 集計の計算を確かめる

掲示板に B の一票が残っていても、サーバーがその票を集計したとは限りません。「64 票を数えました」という説明に加えて、どのプログラムがどの入力を処理し、何を出力したのかを確かめる証拠が必要です。

このデモは、投票の検査と集計を **zkVM** という仮想マシンの中で実行し、その計算の証明を作ります。計算する小さなプログラムをゲスト、実行を準備して証明を作るプログラムをホストと呼びます。

ゲストの出力には、候補ごとの得票数だけでなく、提示されなかった票の数や、実際に計上した位置の記録も含めます。そのため、B の一票を外した入力を正しく集計しても、「1 スロットが未提示」という結果が証明に残ります。証明が有効であることと、投票結果を Verified と呼べることが分かれるのはこのためです。

検証者は、期待する集計プログラムの識別子 **Image ID** を先に選び、そのプログラムの実行証明かを確認します。
