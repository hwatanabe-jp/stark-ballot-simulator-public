# はじめに

> **最終更新:** 2026-10-29

STARK Ballot Simulator は、投票の受付、掲示板への記録、集計、証明生成、検証を行う教育用デモです。投票レシート、掲示板の証拠、STARK 証明を使い、投票内容と記録の一致、集計への採用、計算の正しさを検証します。

投票が正しく集計されたことは、結果画面の得票数と証拠を照合して確認します。このデモでは、票を集計入力から除外したり、表示する得票数を変更したりするシナリオを実行し、各チェックによる検出結果を確認できます。

## デモの構成と制約

投票者は A〜E から一つを選択します。投票者の一票と 63 票のボット投票で、合計 64 票の選挙を構成します。

このシステムは実際の選挙での使用を想定していません。ブラウザは投票 API を通じて投票先と乱数をサーバーへ送信します。公開される証拠から投票先を隠す構成ですが、運営者に対する投票先の秘匿は保証しません。
