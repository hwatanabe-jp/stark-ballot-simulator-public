# 投票の記録を確かめる

B に投票したあとで、サーバーが「受け付けました」と返すだけでは、何を受け付けたのかが残りません。そこで、選択肢と乱数から計算した**コミットメント**を掲示板に記録し、その記録の位置と掲示板の状態を投票レシートとして返します。

この一票が掲示板の先頭、インデックス 0 に入り、その後に 63 票が追加されるとします。確かめたいのは、最初の記録が確かに B を表すことと、64 票になった掲示板にも同じ記録が残っていることです。前者は手元の選択肢と乱数からの再計算で、後者は掲示板のハッシュと Merkle 証明で確認できます。

ただし、自分に見せられた掲示板が筋の通ったものでも、ほかの人に別の掲示板を見せている可能性は残ります。掲示板の状態を表す STH ダイジェストを別の記録源と照合するのは、その食い違いを探すためです。同じサーバーからもう一度値を取るだけでは、独立した確認にはなりません。

記録が残ることと、集計に使われることも別です。集計側はこの掲示板のルートを受け取り、各票がそこに含まれるかを調べます。こうして、投票時の記録が次の計算の基準になります。
