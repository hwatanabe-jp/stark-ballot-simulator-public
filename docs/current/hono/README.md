# Hono API Docs

Hono is the retained API runtime. Current route behavior is defined by
`apps/api/src/server/api/routes/definitions.ts`, bound by
`apps/api/src/server/api/routes/hono.ts`, and implemented in
`apps/api/src/server/api/handlers/`.

Deployment-specific values should be represented as placeholders in current
docs. Operational evidence and historical migration records are kept in the private source repository and stripped from generated public snapshots.
